## Goal

Make a public extension wrapper shaped as `function wrap<T extends AnyCommandDefinition>(definition: T): T { return commandDefinition(definition); }` accept direct inline definition-backed descriptors with unannotated callbacks, without casts, private shape copies, or requiring callers to pre-wrap with `commandDefinition({...})`.

## Acceptance
- `function wrap<T extends AnyCommandDefinition>(definition: T): T { return commandDefinition(definition); }` accepts a direct inline definition-backed descriptor without callback parameter annotations.
- Direct inline wrapper inference exposes composed input enrichment in `validate`, `tags`, `payload`, and `output` callback `ctx`.
- Direct inline wrapper `payload(ctx)` uses schema-input candidate type and `output(event, ctx)` receives parsed `EventOf<typeof Event>`.
- `defineCommand(wrap({ ...bad payload... }))` fails for invalid definition-backed payload fields/types.
- Wrapper returns an exact descriptor type or another safe public descriptor type usable by `defineCommand`.
- No public wrapper-facing `unknown` callback fields or casts remain as the only way to use extension wrappers.
- `commandDefinition(...)` remains runtime identity with no validation, cloning, or normalization.
- Raw-event command descriptor behavior remains unchanged.
- `llms.txt` is updated if public guidance changed; otherwise checkpoint records why no doc update was needed.

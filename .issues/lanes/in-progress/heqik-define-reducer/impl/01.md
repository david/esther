## Work
- Add focused failing coverage first for `defineReducer.fold` reducing from `initial` in event order.
- Add compile-only coverage proving schema tuple inference and `event.type` narrowing inside `reduce`.
- Add compile-only coverage proving a plain reducer-shaped object is rejected where a branded reducer helper/type is required.
- Implement `src/core/reducer.ts` with private `reducerBrand`, exported `ReducerEvent`, exported branded `ReducerDefinition`, and exported `defineReducer`.
- Make `fold` call `descriptor.reduce` in event order starting from `descriptor.initial`.
- Export reducer factory/types from `src/index.ts`.
- Keep this task additive; do not convert `tagQuery`, `castTagQuery`, read descriptors, or event stores yet.

## Acceptance
- `defineReducer` exists in core and root exports.
- Reducer definitions carry a private brand not constructible through normal public imports.
- `ReducerEvent` infers the event union from a readonly Zod schema tuple.
- `fold` returns the state produced by reducing parsed events from `initial` in order.
- No existing raw event-history query API is changed in this foundation task.

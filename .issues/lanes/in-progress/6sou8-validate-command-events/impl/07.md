# 07 — Preserve raw command event path with helper-field collisions

## Goal
Harden `defineCommand` overload discrimination so raw command definitions keep using raw `event(ctx)` even when reusable definition objects carry extra helper properties named `tags` and `payload`.

## Intent / decision vocabulary
- `RawInteropEvent`: raw `event(ctx) => EventRecordInput` path stays deliberate low-level unvalidated interop escape hatch
- `DefinitionBackedCommand`: commands with `event: EventDefinition` build candidates from `EventDefinition.type`, `tags(ctx)`, and `payload(ctx)`
- `CommandEventCandidate`: direct definition-backed `Command.event(ctx)` result before dispatch parse
- `ParsedCommandEvent`: appended event after definition-backed schema parse

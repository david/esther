## Intent / decision vocabulary
- `CommandEventCandidate`: direct definition-backed `Command.event(ctx)` result before dispatch parse
- `DefinitionBackedCommandPayloadInput`: `payload(ctx)` returns event payload schema input
- `ParsedCommandEvent`: appended event and `output(event, ctx)` value after schema parse
- `RawInteropEvent`: raw `event(ctx) => EventRecordInput` path, deliberately unvalidated by event definitions

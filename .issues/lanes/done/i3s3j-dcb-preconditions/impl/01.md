# 01 — Enforce append option-presence semantics in local stores

## Source
- plan/02-implementation-plan.md
- plan/checks/02-plan-sanity.md

## Goal

Make raw `EventStore.append(...)` preconditions active whenever `options` is present for the in-memory and filesystem adapters, including empty-boundary checks where `expectedPosition === undefined`.

## Depends on
- none

## Scope
- `src/core/event-store.ts`
- `src/adapters/in-memory/event-store.ts`
- `src/adapters/in-memory/event-store.test.ts`
- `src/adapters/filesystem/index.ts`
- `src/adapters/filesystem/index.test.ts`

## Contract surfaces
- `AppendOptions` semantics
- in-memory append precondition validation
- filesystem append precondition validation and existing append lock behavior
- `ConcurrencyError` emission shape

## Plan-check watch items
- Use a single helper or clearly duplicated adapter logic for option-present semantics so in-memory, filesystem, and postgres do not drift.
- Preserve the existing `ConcurrencyError` shape exactly while changing when it is emitted.

## Work
- Add focused failing tests for in-memory append options:
  - `{ boundaryTags: ["issue:1"], expectedPosition: undefined }` succeeds while the boundary is empty and fails after a matching event appears.
  - `{ boundaryTags: undefined, expectedPosition: undefined }` succeeds only when the global stream is empty and fails after any event exists.
  - `{ boundaryTags: undefined, expectedPosition: 0n }` succeeds only when global latest position is `0n`.
- Add matching focused tests for the filesystem adapter.
- Update in-memory precondition validation so only `options === undefined` skips the precondition.
- Update filesystem precondition validation so only `options === undefined` skips the precondition.
- Use `options.boundaryTags ?? []` to select the boundary, preserving `undefined` and `[]` as the global stream boundary.
- Preserve existing append success, stale failure, handler, and persisted event behavior.
- Keep any shared helper small and dependency-safe; do not make adapters import each other.

## Acceptance
- In-memory append treats omitted `options` as no precondition.
- In-memory append treats present `options` as an active precondition even when `expectedPosition` is `undefined`.
- Filesystem append treats omitted `options` as no precondition.
- Filesystem append treats present `options` as an active precondition even when `expectedPosition` is `undefined`.
- `boundaryTags: undefined` and `boundaryTags: []` select the global stream boundary.
- Stale failures return the existing `ConcurrencyError` fields without changing their names or meanings.

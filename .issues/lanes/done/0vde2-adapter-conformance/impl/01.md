# 01 — Extract append conformance fixture and wire in-memory

## Source
- plan/01-refactor-plan.md
- plan/checks/01-plan-sanity.md

## Goal

Create the shared, test-only `EventStore.append(...)` precondition conformance suite and prove it against the in-memory adapter first.

## Depends on
- none

## Scope
- `src/__tests__/event-store-append-conformance.ts`
- `src/adapters/in-memory/event-store.test.ts`

## Contract surfaces
- `EventStore.append(...)` test expectations only
- `AppendOptions` semantics: omitted options, present options, `expectedPosition: undefined`, `boundaryTags: undefined`, and `boundaryTags: []`
- `ConcurrencyError` protected fields: `_tag`, `message`, `expectedPosition`, `actualPosition`, `boundaryTags`
- `queryByTags(...)` only as a test assertion tool for event visibility / failed append non-persistence

## Plan-check watch items
- Keep `src/__tests__/event-store-append-conformance.ts` test-only and imported only by `*.test.ts` files.
- Assert the protected `ConcurrencyError` fields, including `_tag`, `message`, `expectedPosition`, `actualPosition`, and `boundaryTags`, without overfitting IDs/timestamps.
- Make the `undefined`/`[]` global-boundary conformance case cross-check both directions (`undefined` seed then `[]`, and `[]` seed then `undefined`).
- If the helper verifies failed appends do not persist events, use `queryByTags(...)` with explicit schemas rather than weakening the assertion to `isErr()` only.
- When removing local duplicate tests, remove only cases exactly replaced by the shared suite; keep handler ordering, query, and storage tests local.

## Work
- Add the shared conformance helper in `src/__tests__/event-store-append-conformance.ts` with an exported `defineEventStoreAppendConformanceTests(adapterName, createStore)` API compatible with `EventStore | Promise<EventStore>` factories.
- In the helper, define explicit event/schema helpers without `Record<string, unknown>` payload value types.
- Cover the six planned conformance cases:
  - omitted options do not activate a precondition;
  - present options protect an empty tagged boundary;
  - `boundaryTags: undefined` protects an empty global stream;
  - `boundaryTags: undefined` and `[]` both select the global stream in both directions;
  - stale tagged boundary returns the expected `ConcurrencyError` and does not append;
  - stale global boundary returns the expected `ConcurrencyError` and does not append.
- Wire the helper into `src/adapters/in-memory/event-store.test.ts` with `createInMemoryEventStore()`.
- Remove only in-memory append-precondition tests exactly replaced by the conformance suite; keep in-memory storage, query, and handler tests local.
- Run the focused in-memory adapter test and fix only issues within this slice.

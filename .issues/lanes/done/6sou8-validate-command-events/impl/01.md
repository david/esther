# 01 — Add event-definition-backed command contract

## Source
- plan/01-implementation-plan.md

## Goal
Add public `defineCommand` form that accepts an `EventDefinition` plus `tags(ctx)` and `payload(ctx)`, with compile-time payload/tag typing and typed `output(event, ctx)` event inference. Preserve existing raw `event(ctx) => EventRecordInput` form.

## Depends on
- none

## Scope
- `src/core/slice.ts`
- `src/core/event.ts` only if helper types are needed
- `src/index.ts` only if new public helper types are needed
- `src/__tests__/type-check.ts`

## Contract surfaces
- public TypeScript DSL: `defineCommand`
- event-definition-backed command definition shape: `event`, `tags`, `payload`
- command internal shape may gain optional event-schema/validator metadata
- raw command event form unchanged

## Plan-check watch items
- Keep `payload(ctx)` typed as `z.output<TPayloadSchema>` to match existing `EventDefinition.create(...)`, unless implementation deliberately narrows/forbids transform-heavy schemas with tests/docs.
- Keep any new casts local to overload normalization and document them per `doc/code-style.md` cast policy.
- If adding optional `eventSchema`/validator to exported `Command` type, keep it optional and non-breaking.

## Work
- Add focused type-check cases first in `src/__tests__/type-check.ts`:
  - valid event-definition-backed command infers output event as `EventOf<typeof Definition>`
  - `payload(ctx)` missing required field fails with `@ts-expect-error`
  - `payload(ctx)` wrong field type fails with `@ts-expect-error`
  - `tags(ctx)` must return `ReadonlyArray<string>`
  - existing raw command form still typechecks
- Add split command definition types/overloads for raw event form vs event-definition form in `src/core/slice.ts`.
- Normalize event-definition form into existing runtime command shape by building event with `definition.event.create({ tags, payload })`.
- Carry optional event schema/validator metadata on command for later pipeline validation; leave raw form with no metadata.
- Keep existing `defineCommand<...>` raw generic call sites compatible.
- Export new helper types only if implementation needs public names for callers or type tests.

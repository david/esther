## Goal

Add CMS-style wrapper type coverage proving a definition-backed command wrapper can replace input, enrich context, widen error unions, merge base and wrapper-owned `outputErr` handlers, and return a definition-backed descriptor without downstream double assertion or private descriptor mirrors.

## Contract surfaces
- TypeScript public API: definition-backed command wrapper descriptor return type
- TypeScript public API: input pipeline, enriched `TCtx`, widened `TError` / `TInputError`, and `OutputErrHandlers`
- event validation contract: wrapper remains definition-backed at type boundary
- auth policy: none; auth/session appears only as wrapper typing fixture

## Plan-check watch items
- Do not hide `TCtx` / `TInput` compatibility problems with a broad cast.
- Type tests must prove base handlers and added handlers receive safe `ctx: TWrappedCtx | TWrappedInput` semantics.
- Keep `commandDefinitionWrapper(...)` limitation clear: direct inline contextual typing belongs to Esther-owned helper/overloads; plain `T extends AnyCommandDefinition` is already-typed forwarding only.
- Run and classify `as unknown as` hits before checkpoint.

## Work
- Add focused type fixture in `src/__tests__/type-check.ts` for a generic authenticated/session wrapper starting from `DefinitionBackedCommandDefinition` and returning `DefinitionBackedCommandDefinitionWithOutputErr`.
- Build wrapper fixture so it replaces raw input with composed authenticated/session input and enriches `TCtx` before command callbacks.
- Assert enriched context/input fields are visible in `validate`, `tags`, `payload`, `output`, and `outputErr` handlers without broad double assertion.
- Assert wrapper widens `TError` and `TInputError` to include `AuthenticatedSessionError`, and adds required handler for that error.
- Assert `mergeOutputErrHandlers(definition.outputErr, authHandlers)` returns `OutputErrHandlers<TError | AuthenticatedSessionError, TOutput, TWrappedCtx, TWrappedInput>`.
- Assert wrapped descriptor remains definition-backed: `event` is `EventDefinition`, `payload(ctx)` accepts `EventPayloadInputOf<typeof Event>`, and `output(event, ctx)` sees `EventOf<typeof Event>`.
- If fixture exposes low-risk generic shape issue from 07, adjust public helper/type narrowly and update docs if user-facing signature changes.

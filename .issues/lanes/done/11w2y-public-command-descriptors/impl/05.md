## Goal

Make `commandDefinition({...})` a safe public inference anchor for inline definition-backed descriptors, matching inline `defineCommand({...})` typing without `never` callback contexts or `unknown` payload/output erasure.

## Plan-check watch items
- Define `AnyCommandDefinition` generics narrowly enough to preserve inference; avoid `unknown`/wide union erasing `TCtx`, `TError`, `TInputError`, or `TEventDefinition`.
- Keep public `commandDefinition(...)` pure identity; no cloning/normalization/validation.
- Preserve existing local cast comments if overload normalization still needs casts; do not add broad wrapper-facing casts.
- When updating `llms.txt`, mention `payload(ctx)`/`command.event(ctx)` uses schema input while `output(event, ctx)` receives parsed `EventOf<typeof Event>`.

## Work
- Add focused type-level regression coverage first in `src/__tests__/type-check.ts` for inline `commandDefinition({ ...definition-backed descriptor... })` with unannotated `validate`, `tags`, `payload`, and `output` callbacks.
- Assert inline callback inference sees composed input context in `ctx`, `output(event, ctx)` sees `EventOf<typeof Event>`, and schema-transform payload/candidate paths use `EventPayloadInputOf<typeof Event>` schema input.
- Add negative type-level coverage proving `defineCommand(commandDefinition({ ...bad payload field/type... }))` fails when `payload(ctx)` returns fields outside `EventPayloadInputOf<typeof Event>`.
- Add wrapper coverage for `function wrap<T extends AnyCommandDefinition>(definition: T): T` accepting valid inline or pre-typed descriptors without casts and preserving returned descriptor type.
- Replace broad public `AnyCommandDefinition` helper shapes that use `never` callback contexts or `unknown` payload/output with inference-preserving generic descriptor constraints or `commandDefinition(...)` overloads mirroring `defineCommand(...)` descriptor families.
- Keep `commandDefinition(...)` runtime implementation as direct identity.
- Check whether `llms.txt` already describes this intended inline/wrapper behavior; update only if guidance would otherwise be stale, and record no-update reason in checkpoint if unchanged.

## Acceptance
- Inline `commandDefinition({ ...definition-backed descriptor... })` no longer contextually types callback `ctx` or `event` as `never`.
- Bad definition-backed payload fields/types are rejected through `defineCommand(commandDefinition(...))`.
- Transform event payload tests prove `payload(ctx)` and command candidates use schema input, while `output(event, ctx)` receives parsed `EventOf<typeof Event>`.
- `T extends AnyCommandDefinition` wrapper preserves valid inline and pre-typed command descriptors without casts.
- `commandDefinition(...)` remains runtime identity with no validation, cloning, or normalization.
- No broad wrapper-facing `unknown` casts or public `never` callback contexts remain in command descriptor constraints.
- `llms.txt` is updated if public guidance changed; otherwise checkpoint records why no doc update was needed.

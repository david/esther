# 01 — Enable no-adapter app construction

## Source
- plan/01-implementation-plan.md

## Goal
Make `createApp({ eventStore, slices })` valid at type level and runtime, with direct `app.dispatch()` and no-op lifecycle when no `inputAdapter` is configured.

## Depends on
- none

## Scope
- `src/core/app.ts`
- `src/core/app.test.ts` or closest core app test location
- `src/__tests__/type-check.ts`

## Contract surfaces
- `AppConfig.inputAdapter` becomes optional.
- `createApp(config)` must not bind or dereference a missing adapter.
- `App.start()` and `App.stop()` remain present and return `Promise<void>`.
- `App.dispatch(sliceName: string, input: unknown)` stays dynamic.
- No event, persistence, read-model, processor, effect, or adapter contract changes.

## Plan-check watch items
- Keep implementation localized to `src/core/app.ts` unless tests reveal real need; avoid production noop adapter.
- Prefer focused `src/core/app.test.ts` coverage over broad integration-test rewrites.
- Preserve exact unknown-slice error text: `Unknown slice: ${sliceName}`.
- Use optional guard/chaining without casts, `Record<string, unknown>`, or new loose object shapes.

## Work
- Add type-check coverage in `src/__tests__/type-check.ts` proving `AppConfig` accepts `{ eventStore: createInMemoryEventStore(), slices: [] }` without `inputAdapter`.
- Add type-check coverage proving `createApp({ eventStore: createInMemoryEventStore(), slices: _typedOperations })` works without `inputAdapter`.
- Add/extend focused runtime app tests for no-adapter construction.
- First failing runtime assertion: no-adapter app can dispatch a small command or query successfully through `app.dispatch(sliceName, input)`.
- Add runtime assertions that unknown slice still throws `Error("Unknown slice: ...")` without an adapter.
- Add runtime assertions that `await app.start()` and `await app.stop()` resolve when no adapter is configured.
- Update `src/core/app.ts`: make `inputAdapter` optional, guard `bind(dispatch)`, and make lifecycle delegate only when adapter exists.
- Keep core free of concrete adapter imports and production noop adapters.

- `AppConfig.inputAdapter` is optional in public type surface.
- `createApp({ eventStore, slices })` compiles.
- No-adapter app creation does not throw.
- No-adapter `app.dispatch(sliceName, input)` executes the existing slice pipeline and returns the same result shape as before.
- No-adapter unknown slice still throws exact `Unknown slice: ${sliceName}` text.
- No-adapter `app.start()` and `app.stop()` resolve with no side effects.
- No new casts, loose object types, concrete adapter imports, or production noop adapter are introduced.

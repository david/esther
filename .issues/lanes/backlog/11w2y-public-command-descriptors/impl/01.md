# 01 — Establish public command descriptor contract

## Source
- plan/01-implementation-plan.md
- plan/checks/01-plan-sanity.md

## Goal

Promote command descriptor names and event candidate helper types to public API, then make `defineCommand(...)` consume those public types without changing runtime command behavior.

## Depends on
- none

## Scope
- `src/core/event.ts`
- `src/core/slice.ts`
- `src/index.ts`
- `src/__tests__/type-check.ts`

## Contract surfaces
- public TypeScript exports: `RawCommandDefinition`, `DefinitionBackedCommandDefinition`, `AnyCommandDefinition`, `commandDefinition`, `EventPayloadInputOf`, `EventCandidateOf`
- `defineCommand(...)` overload parameter types
- root `esther` module export surface
- no persistence, read-model, auth, side-effect, or event wire-shape changes

## Intent / decision vocabulary
- `RawCommandDefinition`
- `DefinitionBackedCommandDefinition`
- `AnyCommandDefinition`
- `commandDefinition`
- `EventPayloadInputOf`
- `EventCandidateOf`
- candidate/input payload vs stored/output event distinction
- `validatedCommandEvent` behavior

## Plan-check watch items
- Define `AnyCommandDefinition` generics narrowly enough to preserve inference; avoid `unknown`/wide union erasing `TCtx`, `TError`, `TInputError`, or `TEventDefinition`.
- Keep public `commandDefinition(...)` pure identity; no cloning/normalization/validation.
- Preserve existing local cast comments if overload normalization still needs casts; do not add broad wrapper-facing casts.
- Negative root-export test for removed `CommandDefinition` should prove absence from package root, not only unused local type behavior.

## Work
- Add focused type-check assertions/imports first for new root exports and removed root-public `CommandDefinition`.
- Add `EventPayloadInputOf<TDefinition>` and `EventCandidateOf<TDefinition>` in `src/core/event.ts` using schema input types.
- Rename raw descriptor type to public `RawCommandDefinition` in `src/core/slice.ts`.
- Promote definition-backed descriptor to exported `DefinitionBackedCommandDefinition` and remove private `EventDefinitionCommandDefinition` shadow.
- Add public `AnyCommandDefinition` union and one-line identity `commandDefinition<T extends AnyCommandDefinition>(definition: T): T`.
- Update `defineCommand(...)` overloads and internal runtime union to consume public descriptor types.
- Export new public names from `src/index.ts`; remove old root `CommandDefinition` export without adding compatibility alias.

## Acceptance
- Root imports compile for `RawCommandDefinition`, `DefinitionBackedCommandDefinition`, `AnyCommandDefinition`, `commandDefinition`, `EventPayloadInputOf`, and `EventCandidateOf`.
- `CommandDefinition` is no longer exported from package root and no deprecated alias exists.
- `defineCommand(...)` overloads refer to public descriptor types, not private `EventDefinitionCommandDefinition`.
- `commandDefinition(definition)` returns same descriptor type at compile time and has no runtime normalization logic.
- Definition-backed descriptor `payload(ctx)` is typed with schema input through `EventPayloadInputOf` / `EventCandidateOf`; `output(event, ctx)` stays parsed `EventOf<typeof Event>`.

Prove processor event handlers receive descriptor-derived typed reads, remove representative manual `unknown` narrowing, and ensure malformed read rows do not allow processor effects to run.

## Contract surfaces
- Public DSL type surface: `processorEvent` handler `reads` inference.
- Read descriptors covered: `getDescriptor`, `queryDescriptor`, `eventsByTagsDescriptor`.
- Side effects: processor effects must execute only after reads resolve and validate.
- No-read runtime compatibility: preserve existing `undefined` second handler argument when processor binding declares no reads.

## Contract surfaces
- Public DSL type surface: `readModelEvent` handler `ctx` read inference.
- Read descriptors covered: at minimum `getDescriptor` and `queryDescriptor`; include event-history reducer read if current DSL supports it for read-model event bindings.
- Projection side effect: projection result must be produced only after reads resolve and validate.
- Existing ctx helpers: preserve `ctx.project(...)` and `ctx.get(...)` behavior and types.

- Add malformed read row rejection before projection if cheap; interpreter tests from task 01 are minimum owner tests.
- Avoid mass-cleaning unrelated explicit `readModelEvent<..., unknown>` call sites unless needed to prove canonical inference.
